# EchoMusic 酷狗概念版 VIP 插件

使用 EchoMusic 当前登录的酷狗账号，自动完成概念版 VIP 领取、每日升级、广告时长和未来日期预领任务。

## 自动任务

插件只提供自动化配置，不提供会员状态面板、刷新按钮或手动领取入口。

启用自动任务后，按以下顺序执行：

1. 领取今日 VIP
2. 可选执行每日会员升级
3. 可选执行广告时长任务
4. 按剩余会员时长预领未来日期

触发时间：

- EchoMusic 启动后等待配置的延迟时间，默认 60 秒
- EchoMusic 保持运行时，北京时间每天 09:00
- 登录态或网络暂不可用时，依次在 10、30、60 分钟后重试
- 从关闭切换为启用，或修改升级、广告、预领配置后，重新安排一次任务

EchoMusic 关闭时插件无法执行；下次启动后会自动补充执行当天任务。

## 配置

- 启用自动任务
- 启动延迟，范围 0–60 秒
- 每日自动升级
- 自动执行广告任务
- 每日广告次数，范围 0–8 次
- 最多预领未来天数，范围 0–7 天
- 任务结果通知

所有设置修改后自动保存。

## 去重和错误处理

插件在内部保存已领取日期、每日升级结果、广告完成次数、当天预领上限和自动执行结果，仅用于避免重复请求，不在界面展示。

以下响应会作为已完成处理：

- 今日已经领取
- 今日已经升级
- 今天广告次数已用光
- 已达到广告每日上限

遇到“未来时长不足”后，当天不再重复请求同一未来日期。只有登录失效、网络错误和服务端临时错误会进入自动重试。

## 实现方式

插件不使用 `ctx.kugou`。它从 EchoMusic 的 Pinia 运行时读取当前酷狗登录态和设备信息，使用 `ctx.net.request` 直接请求酷狗网关，并在插件内实现概念版 Android 请求签名。

插件不会把 Token、MID 或 DFID 写入插件存储。由于使用直连网络能力，Manifest 声明了 `unrestrictedNetwork`。

签名规则和 VIP 接口参数参考 KuGouMusicApi。KuGouMusicApi 使用 MIT License。

## 开发

```bash
pnpm install
pnpm test
pnpm run typecheck
pnpm run build
```

## 安装

在 EchoMusic 的“插件管理 → 插件源”中添加：

```text
https://github.com/heyreborn/EchoMusicConceptVipPlugin
```

刷新在线插件列表后安装“酷狗概念版 VIP”。

## 注意

- 需要先在 EchoMusic 登录酷狗账号。
- 日期和每日调度统一使用 `Asia/Shanghai`。
- 广告任务每次间隔约 35 秒，8 次约需 4 至 5 分钟。
- Pinia 登录态属于 EchoMusic 运行时结构，主程序调整字段时可能需要同步更新插件。
- 相关酷狗接口属于测试性质，活动规则、错误码或接口参数可能变化。
